## 🤔 What is this?

A curated starter library of image-generation prompts for **GPT Image 2.5**, OpenAI's newest image model (launched with ChatGPT Images 2.5 on September 8, 2026 — see the [official announcement](https://openai.com/index/introducing-chatgpt-images-2-5/)).

Every prompt here was **shared publicly on X/Twitter by its original author**. Instead of re-generating lookalike examples, each entry embeds the **real render from the original post** and links straight back to it — so you can always check the source, the author's thread, and how the community iterated on the prompt.

The prompts first circulated during the GPT-Image-2 era and are re-curated here as proven starting points for 2.5: copy one, tweak the subject or style, and run it against `gpt-image-2.5-flare` (fast, default) or `gpt-image-2.5-sunburst` (precision edits).

## 🧭 How to use

1. Browse a category below (or Ctrl+F for a style keyword).
2. Open the **📝 Prompt** collapsible and copy the full text.
3. Prompts tagged ✂️ *Reference-Based Editing* expect you to attach your own reference image(s) first; everything else works as plain text-to-image.
4. Tweak in brackets-style slots (subject, place, text, palette) and re-run. Keep what must not change in its own sentence — that pattern transfers well to 2.5's edits.
